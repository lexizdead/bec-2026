# sosny · День 2 (TD) · прошивка ESP32

Шаблон Ліди (`firmware/template`), адаптований під ESP32 і завдання дня 2.
Логіка = `firmware/day2_robot/sketch.ino` з чату Віталія (той файл лишається для Wokwi).
Скомпільовано: arduino-cli + esp32 3.3.12, 73 % flash. Режим Wokwi (`SIM 1`) теж збирається.

| Файл | Що всередині | Хто править |
|---|---|---|
| `robot/config.h` | піни (= `day2_wiring.svg`), пороги безпеки, дефолти | Ліда, піни — тільки разом з Андрієм/Віталієм |
| `robot/hw.*` | мотори, TCRT, HC-SR04, зумер, серво, збереження налаштувань | рідко |
| `robot/net.*` | Wi-Fi `sosny-robot` / `sosny2026`, сторінка `192.168.4.1` | Ліда (вигляд сторінки) |
| `robot/robot.ino` | стани, лінія, поперечні лінії, безпека, об'їзд, телеметрія, Serial-меню | Ліда + Віталій |

## Як працює
`IDLE` → Старт (кнопка / сторінка / `g`) → `RUN` по лінії (PD по L/C/R) → 4-й сенсор + L/C/R чорні, далі лінія під C → +1 лінія → на N-й `ARRIVED` → `UNLOAD` (серво 2 с) → `DONE`.
Безпека поверх: < 35 см — швидкість ×0.4 + зумер; < 15 см — `ESTOP`; звільнилось на 1 с — їде далі; стоїть > 3 с — `BYPASS` (відвернути → дуга → знайти лінію → доворот). Лінію загублено > 1.5 с — `LOST`.
Телеметрія 2 р/с: стан, % маршруту, **пройдено см**, лінії N/ціль, відстань до перешкоди, перешкоди/об'їзди, АКБ, час, 4 датчики, журнал 8 подій.

## Перший запуск на роботі (≈20 хв)
1. `make setup` — **зараз**, поки чекаєте принтер (качає ~500 МБ).
2. `make upload`, `make monitor`, `h` — меню.
3. `m` — колеса крутяться вперед? Ні → `MOTOR_L_INVERT` / `MOTOR_R_INVERT` у `config.h`.
4. `u` — HC-SR04 показує відстань до руки.
5. `c` — 5 с водіть роботом над білим і чорним (калібрування збережеться). `s` — перевірка: на чорному ~1000, на білому ~0.
6. Поставити на лінію, `g`. Виляє → менше `P` або більше `D` (`P60`, `D50`). Не встигає в поворот → менше `B` або більше `V`.
7. «Пройдено, см»: проїхати 1 м по прямій з `B` за замовчуванням, засікти час → `M` = 1000 / секунди. `w` — зберегти.
8. Об'їзд: поставити коробку на лінію, підібрати `T` (відвернути), `I`/`E` (дуга), `A` (мін. час дуги). Коробок на лінії не буде → `O0`.

## Звірено з фізичними деталями
- Сенсори L/C/R крок 15 мм, 4-й на 35 мм, висота 6 мм — `sensor_bracket.scad`. Поперечні лінії мають бути довші за ~41 мм від центру лінії, інакше 4-й їх не побачить.
- Сенсори лише ~40 мм перед ведучою віссю (не 60) — поворот реагує швидше, тому `KP` 70 / `KD` 40 як стартові, підбирати.
- Енкодерів нема → «пройдено» і об'їзд за часом. Задні колеса друковані, ковзають — розворот на місці працює.
- Перемички ENA/ENB на L298N зняти (ШІМ з GPIO25/18). TCRT живити від 3.3 В. ECHO через 1k/2k.
