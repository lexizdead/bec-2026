# Перевірка в Wokwi (без заліза)

1. wokwi.com → **New Project** → **ESP32**.
2. Вкладка `sketch.ino`: стерти все й вставити вміст `robot/robot.ino`.
3. Кнопка **▾** біля вкладок → **New file…** → створити по черзі `config.h`, `hw.h`, `hw.cpp`, `net.h`, `net.cpp` і вставити в кожен вміст однойменного файлу з `robot/`.
4. У `config.h` поставити `#define SIM 1` (Wi-Fi у симуляції вимкнено, керування з Serial).
5. Вкладка `diagram.json`: стерти й вставити наш `diagram.json`.
6. **▶ Start**. Унизу Serial Monitor: кожні 0.5 с рядок JSON; команди пишемо в поле вводу.

## Що є що
| На схемі | Що імітує |
|---|---|
| 4 повзунки (згори вниз) | TCRT L, C, R, X (4-й). **Вправо = чорне** |
| HC-SR04 | клікнути → повзунок відстані |
| Зелена / червона кнопка | START / STOP |
| Жовті LED M1/M2 PWM | швидкість лівого / правого колеса (яскравість) |
| Зелений / червоний LED M1, M2 | вперед / назад; усі горять = гальмо |
| ЇДУ / СТОЮ | зовнішні світлодіоди для людей |
| ◀ ПОВОРОТ / ПОВОРОТ ▶ | поворотники + «тік-так» зумера |

## Сценарії
1. **Прямо:** C вправо, L і R вліво → `g` → M1 і M2 однаково, ЇДУ горить.
2. **Поворот ліворуч:** L вправо, C трохи → M1 тьмяніє, блимає **◀ ПОВОРОТ** і цокає зумер.
3. **Різкий поворот:** після кроку 2 усі вліво → розворот на місці, поворотник далі блимає; > 1.5 с → `LOST`.
4. **Перешкода:** відстань 30 см → повільніше + пищить; 10 см → `ESTOP`; 50 см → через 1 с їде далі.
5. **Об'їзд:** 10 см і тримати > 3 с → `BYPASS`: блимає ПОВОРОТ ▶ (відвертає), потім ◀ (дуга назад до лінії). Опустити всі повзунки лінії, через ~1 с підняти C → «об'їзд завершено».
6. **Поперечна лінія:** усі 4 вправо, потім L, R, X вліво (C лишити) → «лінія 1/3». Тричі → `ARRIVED` → серво → `DONE`, 100 %.
7. Команди: `h` меню, `g` старт, `x` стоп, `n2` ціль = 2-га лінія, `p` налаштування.
