# Симуляція робота в Wokwi

## Запуск (1 хв)
1. wokwi.com → New Project → **ESP32**.
2. Вкладка `sketch.ino` → вставити наш `sketch.ino` (на початку `#define SIM 1`).
3. Вкладка `diagram.json` → вставити наш `diagram.json`.
4. ▶ Start. Унизу Serial Monitor: кожні 0.5 с рядок телеметрії, в поле вводу пишемо команди.

Команди: `s` старт · `x` стоп · `n3` зупинитись на 3-й лінії (зберігається після перезапуску).

## Що є що
| На схемі | Імітує |
|---|---|
| 4 повзунки зверху вниз | TCRT L, C, R, 4-й (перпендикулярні лінії). Вгору = чорне |
| Крутилка | напруга АКБ (≈7.5 В на старті) |
| Зелена / червона кнопка | START / STOP |
| HC-SR04 | клікнути на нього → повзунок відстані |
| Серво | кузов (на прибутті нахиляється й повертається) |
| Жовті LED | швидкість M1 / M2 (яскравість = PWM) |
| Зелені / червоні LED | мотор вперед / назад; **усі горять = активне гальмо** |
| LED «ЇДУ» / «СТОЮ» (над платою) | зовнішні індикатори робота: зелений = їде (RUN, об'їзд), червоний = стоїть |

## Сценарії перевірки
1. **Прямо:** C вгору, L і R вниз → `s` → обидва жовті однаково, зелені горять.
2. **Поворот:** C вниз, L вгору → ліве (M1) тьмяніє → робот повертає вліво.
3. **Різкий поворот:** після кроку 2 усі вниз → M1 назад, M2 вперед (розворот туди, де була лінія). Тримати > 1.5 с → `LOST`, стоп.
4. **Перешкода:** відстань 30 см → швидкість падає, зумер пищить. 10 см → `ESTOP`, гальмо, безперервний зумер. 40 см → через 1 с їде далі сам.
5. **Перпендикулярна лінія:** усі 4 повзунки вгору, потім L, R і 4-й униз (C лишається вгорі) → `cross 1/3`. Якщо опустити й C → `corner, not counted` (це кут лінії, не перехрестя). Тричі → `ARRIVED` → серво нахиляє кузов → `DONE`, прогрес 100 %.
6. **Об'їзд:** відстань 10 см і тримати > 3 с → `BYPASS`: M1 вперед / M2 назад (відвертає вправо), потім обидва вперед, M2 яскравіше (дуга вліво навколо коробки). Одразу опустити всі повзунки лінії (робот з'їхав з лінії), через ~1 с підняти будь-який повзунок лінії → доворот, потім C вгору → `bypass done`, далі `RUN`.
7. **STOP:** червона кнопка в будь-який момент → гальмо, `IDLE`.

## На справжньому роботі
`#define SIM 0` → ESP32 роздає Wi-Fi `sosny-robot` (пароль `sosny2026`), телефоном відкрити `192.168.4.1`: Старт/СТОП, номер лінії, стан, %, відстань, АКБ.
Перед виїздом: виміряти `WHITE`/`BLACK` (сирі значення TCRT на білому й чорному) і вписати в налаштування на початку файлу.

## Об'їзд перешкоди
Перешкода < 15 см → стоп і зумер (людина пройде — їде далі). Стоїть довше 3 с → об'їзд праворуч: відвернути ~60–90°, дуга навколо, знайшли лінію → доворот, далі по лінії. Енкодерів нема, тому об'їзд за часом: `T_TURN`, `ARC_IN/ARC_OUT`, `T_ARC_MIN` підібрати на трасі під розмір коробки. Сторона — `BYPASS_SIDE`, вимкнути — `BYPASS_ON = false`.
